# 用偏斜样片核对法线 UV

## 任务

在比较法线接缝前，先证明节点读的是正确的切线基；把原生 Normal 烘焙和普通 RGB 扩边分开验。

## 输入

使用一片平面、两个相差 90° 的 UV 岛、正面视图和单位变换。用 OpenGL +Y、Non-Color。保持采样 UV 与 Normal Map 节点的 UV 名称可独立控制。

## 执行

1. 用常量 RGB `(0.8, 0.5, 0.9)`、强度 1 试正确命名的 UV。用线性 EXR 记录 `0.5 × N + 0.5`，读回后解码到世界空间。再试强度 0，以及强度 1 但只把 Normal Map 的 UV 名改成不存在的名称。
2. 在旋转岛上改用为该岛编码的 `(0.5, 0.2, 0.9)`，确认两侧回到同一方向。保留同 RGB 对照，显示方向确实随基变化。
3. 用原生 `NORMAL / TANGENT` 比较零扩边、Extend 8 与请求 Adjacent Faces 8。另用 `EMIT` 存已编码 RGB 做对照，别把这条路径当原生切线法线烘焙。

## 通过条件

正确 UV 的法线向 +X 倾斜 36.87°。两种未施加扰动的对照回到 +Z。在固定实验中，原生两种 8 px 请求的像素与 EXR 字节相同，和零扩边的差异只在岛外。两个岛的世界方向相同不要求其 RGB 相同。

## 失败处理

正确 UV 也返回 +Z，就查节点 UV 名称、切线、切线符号及采样接线，先让偏斜样片通过。外部扩边发现 donor RGB 跨岛时，按接收岛切线基重投影并复验，或用本岛 Extend 作基线。按目标滤波尺度另验；把源贴图里某个 gutter 像素的方向误差直接当成画面接缝会误判。
