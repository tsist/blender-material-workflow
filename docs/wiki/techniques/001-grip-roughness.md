# 把手只改粗糙度

<!-- wiki-index: {"id":"MW-001","title":"把手只改粗糙度","stage":"mask","material":"喷漆钢","effect":"握位抛光","channel":"Roughness","symptom":"抛光把底色改灰或金属度下降","evidence":"single","applies":"0.9.2 主机基线；修复未复验"} -->

适用：0.9.2 主机基线；修复未复验。证据：单件复现（按所列范围）。

## 任务

隔离握位抛光，只改变粗糙度。

## 输入

底钢：线性 RGB (0.26, 0.28, 0.30)，金属度 1，粗糙度 0.34。抛光目标 0.15。遮罩采样 0、0.5、1。

## 执行

运行[命令与对照图](../labs/mask-baseline.md)。对修复候选重跑相同输入，逐通道取样。

## 通过条件

三处粗糙度依次为 0.34、0.245、0.15，底色与金属度保持输入值；主机误差 ≤ 0.000001。Blender 冷重开后重测。

## 失败处理

金属度随权重变为 1、0.5、0：修正图层的通道参与规则。旧清单使用原有混合契约；新清单用显式通道选择。

## 证据

主机基线复现串改；Blender 修复未复验。[版本与命令](../labs/mask-baseline.md)。
