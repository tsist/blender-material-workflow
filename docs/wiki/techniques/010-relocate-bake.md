# 搬运贴图后核对摘要再重建

<!-- wiki-index: {"id":"MW-010","title":"搬运贴图后核对摘要再重建","stage":"export","material":"通用","effect":"依赖回读","channel":"全部","symptom":"贴图搬走后重建提示资源不见或变化","evidence":"single","applies":"0.9.2 报告源码与主机磁盘夹具"} -->

适用：0.9.2 报告源码与主机磁盘夹具。证据：单件复现（按所列范围）。

## 任务

区分路径失效、内容变化、读图语义错误。

## 输入

保留原始 bake 报告、每图 SHA-256、尺寸、位深、色彩空间和目标 UV 名称。

## 执行

复制贴图与报告；先对每个新文件核对原摘要。0.9.2 重建要求报告指向可读绝对路径，在新报告副本重指且保持原摘要。随后用干净工程回读，同光对照。

## 通过条件

同一文件复制后摘要相同。16-bit 样本改一个码值，文件头尺寸和深度不变但摘要改变，应拒绝。已验证报告、位深和色彩空间是不同检查项。

## 失败处理

只失效路径则改报告副本中的路径；摘要不同则找回原图或重烘焙，不用更新摘要掩盖变化。Normal 已包含同一浮雕时，Height 仅保留为辅助资源。

## 证据

[磁盘正反例](../labs/texture-contract.md)；[0.9.2 重建校验](https://github.com/tsist/blender-material-workflow/blob/9d560ee71fa9ece6dab007f2159541823eb9c093/procedural_bake.py#L844)；生产重开未复验。
