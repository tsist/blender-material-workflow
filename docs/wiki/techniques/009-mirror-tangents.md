# 区分镜像切线与绿色轴错误

<!-- wiki-index: {"id":"MW-009","title":"区分镜像切线与绿色轴错误","stage":"export","material":"通用","effect":"镜像接缝","channel":"Normal","symptom":"只有镜像侧的刻痕凹凸反了","evidence":"single","applies":"数学夹具；目标渲染器未复验"} -->

适用：数学夹具；目标渲染器未复验。证据：单件复现（按所列范围）。

## 任务

用非对称刻痕定位切线手性、Y 约定或三角化错误。

## 输入

一对不重叠的普通／镜像 UV；非零 Y 的切线法线；同一面角法线和固定三角化派生副本。

## 执行

用同一基底烘焙并重建。分别制作故意翻绿和改变对角线的反例。在相同掠射光看镜像边；保留源控制笼。

## 通过条件

数学夹具：使用同一带符号基底角差 0°，额外反绿约 73.74°。翘曲四边形切不同对角线时中心高程 0.5／0.0。数值只用于辨别夹具反例。

## 失败处理

仅镜像侧错先核手性和 UV 层；全图方向反先核 Y 约定；沿内部对角线出现差异先固定两端三角化。不用逐岛盲目反绿。

## 证据

[实跑夹具](../labs/texture-contract.md)；[MikkTSpace 契约](https://github.com/mmikk/MikkTSpace/blob/3e895b49d05ea07e4c2133156cfa94369e19e409/mikktspace.h)。
