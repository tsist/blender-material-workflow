# 定位窄阈值造成的局部遮罩跳变

## 任务

定位细碎掉漆是在原始辅助图、窄阈值、图层合成，还是 UV 缩图时发生变化。

## 输入

锁定白模、UV、随机种子、灯光和最终输出规格。按几何选一个目标箱角、一条有两侧对应关系的实际 UV 切口和一块同件平面作对照。读取实际连入重映射节点的信号，不用名称接近的上游节点替代。

## 执行

1. 烘焙重映射前的值、重映射后遮罩和最终粗糙度。数每个区域落在实际过渡区间的纹素和两组并集，再比较同一批纹素的遮罩差异。不要以 0.5 硬切代替真实过渡。
2. 同一条几何边等距取样；在两边各向面内偏移相同实物距离，再分别查各自 UV。保留原始两侧色差，用缩图相对原图的偏移来判断额外渗色。
3. 固定机位复渲柔光、掠射光下的作者版和纯贴图版。CPU 缩图用于排查扩边，不记为目标引擎 mip 实测。

## 通过条件

重映射前后和最终粗糙度能在同一局部对应；照明和视点完全一致。只有在交付镜头出现可复验的改善，才升级该辅助纹理位深。原始位深与最终烘焙位深分别记录。

## 失败处理

差异集中在阈值区：先调整局部权重或过渡宽度。原图正常、缩图异常：先做扩边负对照，并核查邻岛距离。两侧在原图就不一致：先核查 UV 采样、法线和实际材料，不把真实面差当渗色。
