# Material Workflow 工艺 Wiki

按任务打开一个入口，找到工艺页，按「输入 → 执行 → 通过条件」操作。每项工艺只维护一份正文。

- [做资产](indexes/make-assets.md)：按烘焙、图层和遮罩、做旧、导出推进。
- [查工艺](indexes/find-technique.md)：按材料、效果和通道定位。
- [排故](indexes/troubleshoot.md)：按看到的症状定位。
- [原始资料与取舍](sources/comparison.md)：商业工具、开源实现、教程和许可。

## 如何读证据

| 等级 | 用途 |
| --- | --- |
| 来源已核 | 查资料和设计测试。查看每页「证据」所标的具体未做项。 |
| 单件复现 | 在该页列明的环境和输入上试做。主机数学测试不替代 Blender 实测。 |
| 独立复验 | 第二形体或干净工程独立跑通，符合条件的配方进入智能材质库。 |

新页填唯一 ID、适用版本、工序、材料、效果、通道、症状和证据等级。正文用六个固定小节，每步写清输入和判定，不写模糊指令。复验证据默认给命令、条件、预期、正例与反例截图；工件另链。用 `python scripts/check_wiki.py --write` 更新三个索引，用 `python scripts/check_wiki.py` 校验字段、覆盖、断链和索引版本。
