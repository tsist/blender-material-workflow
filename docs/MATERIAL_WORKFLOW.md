# Existing Material Workflow 0.7.0

Repository separation does not change execution. The original [workflow and installation guide](https://github.com/tsist/blenderctl/blob/main/docs/MATERIAL_WORKFLOW.md) remains applicable. Download unchanged plugin and skill packages from this repository's [v0.7.0 release](https://github.com/tsist/blender-material-workflow/releases/tag/v0.7.0).

Plugin backend configuration and skill `BLENDERCTL_ROOT` still refer to a normal blenderctl checkout. The original CLI continues shipping its material modules, without submodules. Existing software/skill contracts and historical verification boundaries are unchanged.
